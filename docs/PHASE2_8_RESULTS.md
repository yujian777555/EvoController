## Task 1：Oracle 可学性基准 —— 已完成，结论明确

**问题（RQ1）**：在冻结的 compact 表示下，action 效应**原则上是否可学**？

**协议**：与最终目标对比**完全相同的数据与 state 级划分**
（`results/phase2_75d/dataset_final`，1200 状态，960 训练 / 240 留出，39,600 样本），
但学习器换成强非神经基线：OLS、随机森林（200 树）、直方图梯度提升（300 迭代）。
逐 horizon 训练（行自带 horizon 标签）。工件：`results/phase2_75d/oracle_learnability.json`。

### 结果（240 留出状态；随机基线：oracle hit 0.091、top-3 0.273）

| model | ρ h=5/10/20 | top-3 h=5/10/20 | oracle hit h=5/10/20 | **action sensitivity** h=5/10/20 |
|---|---|---|---|---|
| linear OLS | 0.060 / 0.031 / 0.043 | 0.288 / 0.254 / 0.225 | 0.100 / 0.083 / 0.092 | 0.033 / 0.034 / 0.026 |
| random forest | 0.024 / 0.048 / 0.035 | 0.288 / 0.292 / 0.250 | 0.087 / 0.096 / 0.075 | **0.226 / 0.220 / 0.210** |
| hist grad boosting | 0.044 / 0.042 / 0.012 | 0.383 / 0.342 / 0.288 | 0.138 / 0.083 / 0.104 | 0.069 / 0.063 / 0.105 |
| （Phase 2.75D MLP） | 0.012 | — | 0.092 | **0.001** |

`action sensitivity` = 同状态内 预测 std / 真实 std；**= 1 表示模型完全复现 action 效应，
= 0 表示完全忽略 action**。

### 结论：**表示 / 动作设计是约束瓶颈**（按计划书自身的判据）

计划书的决策规则是："If oracle models fail, the issue is representation/action design.
If oracle models succeed, the issue is objective optimization."

**两个问题同时存在，但约束性的是表示设计**：

1. **优化问题确实存在且可修**：随机森林的 action sensitivity 达 **0.21**，
   是 MLP（0.001）的 **200 倍**——说明神经网络的失败有相当部分来自优化目标
   （按状态居中的 MSE 以"预测常数 0"为局部最优），而非信号不存在。
2. **但即使修好优化，天花板仍在随机附近**：三个强基线的 within-state 排序质量
   （ρ 0.012–0.060、oracle hit 0.075–0.138、top-3 0.225–0.383）**全部落在随机基线的
   噪声范围内**。即：**在 4 维 action 特征 + 60 维 state 历史的表示下，
   无法从状态预测"哪个动作在同状态内更好"**。

**因此**：Phase 2.8 的 RQ1 答案是"**当前表示/动作设计下不可学**"。
继续投入排序损失（RQ2）或 action encoder（RQ3）**只能把 sensitivity 从 0.001 拉到 0.21，
不能把排序从随机拉到有效**——因为后者的瓶颈不在这里。

## 对后续的直接含义

1. **Task 2（排序损失）与 Task 3（action encoder）应当降级为"次要"**：
   它们能解决 sensitivity 问题（有价值，且 MLP 的 0.001 本身是缺陷），
   但**不能**解决可学性上界问题。计划书要求 gate 1（sensitivity）与 gate 2（排序优于随机）
   同时满足——**gate 2 在当前表示下已被证明达不到**。
2. **真正的杠杆是表示/干预设计**，候选方向：
   - **动作表示**：4 维（multiplier / exploration / 2×one-hot）过于粗糙。可考虑
     动作的**结果签名**（如该动作在若干探针状态上的实际效果）或更长作用的宏动作
   - **状态表示**：60 维窗口（10 代 × 6 统计量）可能抹掉了决定"该动作好不好"的
     关键种群结构（如目标空间分布、局部最优结构、拥挤度分布）
   - **干预设计**：当前 10 个随机采样动作跨越整个 action 空间，**可能根本没有覆盖
     "同状态下真正有区分度的动作对比"**。可以先做一个小实验：在同一状态下只比较
     两个极端动作（极小 vs 极大探索），看可区分性是否远高于 12 候选随机布局
   - **预测目标**：预测 20 代后的绝对增量本身噪声很大（同状态重复噪声 std 0.017，
     而候选间 std 仅 0.03–0.09）。可改为预测**符号/序**或更长 horizon
3. **Phase 3（Mamba/SSM）仍然不成立**：本次结论进一步确认瓶颈不在序列建模。
